# Rolling Razors image slots

Set `VITE_ASSET_MODE=local` when client photography is available. Until then, the default placeholder mode renders branded, non-broken SVG slots.

The current service-card reference photos are temporary visual references for stitching, leather seats, and paint-booth work. Replace them with Rolling Razors-owned project photography before launch.

| Slot | Aspect | Minimum width | Shot brief |
| --- | --- | ---: | --- |
| `hero/hero-01..03` | 3:2 | 2400px | Finished interior, wide, workshop lighting |
| `services/*` | 4:3 | 1600px | The specific service being performed |
| `portfolio/*-before` / `*-after` | 3:2 | 1600px | Identical camera position and crop |
| `materials/material-01..04` | 16:10 | 1200px | Material macro with grain and stitch visible |
| `team/*` | 1:1 | 400px | Real staff portrait, not a stock avatar |
